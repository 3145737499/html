# 熊出没 · 狗熊岭登录网站（多风格演示）

纯前端登录 + 个人中心演示，包含 **4 种视觉风格**，均为单文件 HTML，浏览器直接打开即可运行（无后端）。

## 风格一览

| 文件 | 风格 | 特点 |
|------|------|------|
| `index.html` | 森林高级风 | 毛玻璃 + 流动渐变背景 + 极光光斑 + 飘落树叶 + 3D 倾斜，昼夜切换 |
| `login-cartoon.html` | 卡通明亮风 | 蓝天白云、圆润按钮、弹跳动画、emoji 庆祝，适合儿童向 |
| `login-neon.html` | 暗夜霓虹风 | 深色网格背景、青/品红霓虹辉光、未来感 |
| `login-minimal.html` | 极简风 | 米白底、大量留白、单一绿色强调，干净克制 |

## 通用功能
- 账号 / 密码输入，实时格式校验（邮箱 / 手机号 / 用户名）
- 密码显示 / 隐藏切换
- 「记住我」（`localStorage` 回填）
- 登录成功彩带 / emoji 庆祝，自动跳转个人中心
- 顶部导航在「首页 / 登录 / 个人中心」间切换
- 第三方登录（微信 / Apple / QQ）占位入口

## 预览
直接双击对应 HTML 文件，或用浏览器打开。若开启 GitHub Pages，仓库根目录的 `index.html` 即森林高级风主页。

> 演示作品，登录逻辑为前端模拟，未接入真实后端。
